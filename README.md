# Автоматизация сверки координат и телематики (Advantum <-> 1С)

Проект автоматизирует рутинный процесс проверки и корректировки координат точек доставки:
1. Заходит в **Advantum**, открывает раздел `Рейсы` -> `Все` с фильтром по датам.
2. Находит рейс по номеру и считывает точки со статусом **«Не пройдена»**.
3. Запрашивает эталонные координаты адреса в **Яндекс Картах** и рассчитывает смещение.
4. В **1С:Предприятие** (ЕИС МСК) находит строку в «Адреса доставки», открывает карточку, записывает новые Широту/Долготу/Радиус и сохраняет.
5. Возвращается в **Advantum** и автоматически нажимает **«Пересчитать телематику»**.

```text
Documents/Координаты/
├── config.py             # Загрузка настроек из .env

├── onec_service.py       # Автоматизация 1С (pywinauto на Windows, Mock-симулятор на Mac)
├── run.py                # Главный запускаемый файл CLI
├── test_mock_run.py      # Тест цикла без открытия браузера
├── requirements.txt      # Зависимости
└── .env                  # Логин и пароль от Advantum
```

## Запуск на macOS (Тестирование и Аудит)

Для отладки и проверки рейсов без взаимодействия с 1С (на Маке 1С эмулируется):

```bash
# 1. Быстрый тест без браузера:
python3 test_mock_run.py

# 2. Реальный заход в Advantum (только аудит, без изменения 1С):
python3 run.py --trip 15053328 --date-from 01.10.2026 --date-to 30.10.2026 --dry-run

# 3. Полный цикл (с эмуляцией 1С и нажатием 'Пересчитать телематику' в Advantum):
python3 run.py --trip 15053328 --date-from 01.10.2026 --date-to 30.10.2026 --radius 300
```

## Развертывание и запуск на корпоративном ПК (Windows с 1С)

1. Скопируйте папку `Координаты` на ваш корпоративный компьютер.
2. Откройте командную строку (cmd) в этой папке и установите зависимости:
   ```cmd
   pip install -r requirements.txt
   ```
3. Убедитесь, что на компьютере запущена **1С:Предприятие (ЕИС МСК)**.
4. Запустите скрипт:
   ```cmd
   python run.py --trip 15053328 --date-from 01.10.2026 --date-to 30.10.2026
   ```

### Параметры запуска:
* `--trip <номер>` — номер рейса (обязательный).
* `--date-from <ДД.ММ.ГГГГ>` — дата начала диапазона (по умолчанию: 7 дней назад).
* `--date-to <ДД.ММ.ГГГГ>` — дата окончания диапазона (по умолчанию: сегодня).
* `--radius <число>` — задать новый радиус зоны в метрах (например, `--radius 300`).
* `--dry-run` — только проверить точки, не вносить изменения в 1С.
* `--no-recalc` — не нажимать кнопку пересчета телематики в Advantum.
* `--headless` — запустить браузер скрытно.
